Correctly using PlaceholderAPI on JoinLeavePlus

If you are using JoinLeavePlus 1.7, you have access to PlaceholderAPI. To show you how to use this correctly, I will be giving a tutorial on showing someone's rank in the join message.

  • Your first step is to download PlaceholderAPI, LuckPerms, and JoinLeavePlus. Make sure you have a rank and a prefix in LuckPerms!
  • Next, go into your server. You will now do /papi ecloud download LuckPerms. This command allows LuckPerms placeholders to work.
  • Now, go to the JoinLeavePlus config, and place the placeholder, in this case, %luckperms_prefix% where you want someones prefix at.
  • Finally, run /jlp reload for your changes to be applied.

If you have any questions, go to the Github repo and create an issue.
